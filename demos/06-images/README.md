# 6. Turn ideas into images

**Goal:** generate and refine an image in the conversation, no context switch.

## Steps
1. New session on this repo. Prompt:
   > Create a cartoonish illustration of a shopping cart being fixed by a friendly robot, for the sample-app README.
2. Refine: *"Make it flat, blue/green palette, no text."*
3. Optional: attach a reference image and ask for a variation.
4. Save the final into `assets/` and ask Copilot to reference it from the README.

## Talking points
- Same session, same context: images next to code and docs.
- Great for README banners, slide art, UI mood boards.
